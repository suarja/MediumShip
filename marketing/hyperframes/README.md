# Knowly — Marketing HyperFrames

Pipeline to produce carousels (5 PNG) + a vertical promo video (~19s MP4, 1080×1920)
for TikTok / Instagram Reels / YouTube Shorts and the App Store App Preview slot.

Adapted from the Editia `marketing/hyperframes` pipeline, re-skinned to the Knowly
brand (warm editorial — see `design.md`).

## Stack

- **HyperFrames** v0.5+ — HTML composition, GSAP animation, headless-Chrome render.
- **Node ≥ 22** — preprocessor `scripts/build.mjs`.
- **ffmpeg** + **jq** — extract carousel frames from the rendered MP4.
- Fonts are fetched from Google Fonts at render time (Newsreader · Hanken Grotesk · JetBrains Mono).

## Layout

```
marketing/hyperframes/
  index.html               ← generated by build.mjs (do not hand-edit)
  design.md                ← brand spec (palette, type, motion, copy/timing rules)
  package.json
  components/classic/       ← 5 sub-component sources (pure, Knowly-skinned)
    slide-hook.html         ← eyebrow + hook + italic subline + brand
    slide-stat.html         ← captionTop + number + unit + captionBottom + subline
    slide-body.html         ← mono eyebrow + 3 serif beats (line2 italic) + brand
    slide-screenshot.html   ← caption + phone frame (real screen OR editorial mock) + KPI pill
    slide-cta.html          ← Knowly wordmark + 2 taglines + CTA + handle + footnote
  carousels/               ← source of truth for copy (1 manifest JSON per carousel)
    knowly-media-premium-1.json
  assets/
    app-screens/           ← real Knowly iOS captures (slide-screenshot `screenshotSrc`)
    logos/
  scripts/
    build.mjs              ← reads JSON → patches components → writes index.html
    build.sh               ← wrapper
    render.sh              ← build + render → output/
    manifest.mjs           ← scans carousels/ → manifest.json (integrator index)
  .build/<slug>/           ← gitignored — patched components per carousel
  output/<slug>/           ← gitignored
    video.mp4
    slides/01.png … 05.png
```

## Production loop

```bash
cd marketing/hyperframes

# 1. Install (once)
bun install            # or npm install

# 2. Build + render the carousel → MP4 + 5 PNGs
bash scripts/render.sh knowly-media-premium-1

# Preview live in HyperFrames Studio while authoring
npx hyperframes preview      # http://localhost:3002

# Lint / validate before render
npx hyperframes lint && npx hyperframes validate
```

## New carousel

```bash
# 1. Duplicate a manifest
cp carousels/knowly-media-premium-1.json carousels/<new-slug>.json

# 2. Edit the copy: the 5 slides[].vars in the JSON (see design.md for char limits)

# 3. Build + render
bash scripts/render.sh <new-slug>
```

Copy lives **in the JSON manifest**. Never edit the `components/` sources for copy —
`build.mjs` writes patched copies into `.build/<slug>/`, keeping the sources pure and
the git diff clean. The slug prefix routes module hints in `manifest.mjs`
(`mobile-` / `web-` / otherwise `cross`).

## Slide types

| Type | Usage | Key vars |
|---|---|---|
| `slide-hook` | Opening punch | `eyebrow`, `hook`, `subline`, `brand` |
| `slide-stat` | Big number + payoff | `captionTop`, `number`, `unit`, `captionBottom`, `subline` |
| `slide-body` | 3-beat declarative | `eyebrow`, `line1`, `line2` (italic), `line3`, `brand` |
| `slide-screenshot` | Phone frame + real screen or editorial mock | `caption`, `handle`, `screenshotSrc`, `mockKicker`, `mockTitle`, `mockMeta`, `kpiLabel`, `kpiValue` |
| `slide-cta` | Wordmark + 2 taglines + CTA | `tagline1`, `tagline2` (italic), `cta`, `handle`, `footnote` |

To use a real app capture in `slide-screenshot`, set `screenshotSrc` to a path relative
to `marketing/hyperframes/` (e.g. `"assets/app-screens/home-fr.png"`). When set, it
replaces the editorial mock fallback. Capture real screens via the Expo-web + headless
Chrome protocol in `docs/agents/ui-visual-testing.md`.
